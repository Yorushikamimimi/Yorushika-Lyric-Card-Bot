# ヨルシカ视觉工房

把用户的偏好转成几张可直接使用、可追溯来源的图片。壁纸保留真实 Live 的摄影感；头像保留手绘的简洁和不规则，不用光滑 3D、过量装饰或假日文填满画面。

## 接手与连续扩充

先读项目根目录 [AGENTS.md](../../../AGENTS.md)、[CURRENT_PROGRESS.md](../../../CURRENT_PROGRESS.md) 与 [VISUAL_GUIDE.md](../../../VISUAL_GUIDE.md)，实际打开相关校准图后再选片。选图标准、正反例和增量闭环以VISUAL_GUIDE为准，当前暂停项以进度为准。

用户已确认使用方式：向本机当前GPT主控提新增要求，GPT会话配合本机工具负责提取、制作、入库和验证，用户刷新现有网页即可；不建设外置Agent服务。保持本地网页，不做App、其他客户端或后台自动任务；不让用户自己编辑manifest。旧1080p MV不继续批量放大；用户提供的新源须实测并重新选帧，是否恢复制作以CURRENT_PROGRESS及最新用户要求为准。用户整体喜欢非MV作品，但没有逐张确认所有文件。

## 先选工作流

- **Live 壁纸**：使用项目根目录的 `live_wallpaper.py`。先读 [live-workflow.md](references/live-workflow.md)。默认素材目录是 `/Users/yang/Movies/Bili23-Downloader/Yorushika_Live`；路径不存在时再询问。电脑与手机分别选构图，不能把横屏直接居中裁成竖屏就当作完成。
- **头像 / 简笔插画 / 插画壁纸**：先读 [visual-sources.md](references/visual-sources.md) 中相关角色，以及 [avatar-workflow.md](references/avatar-workflow.md)。生成和重绘必须由当前 GPT Agent 调用内置 `image_gen`，网页只整理需求并展示成品。用途不限于头像：电脑与手机插画壁纸必须按横竖比例独立构图。
- **网页挑选**：在项目根目录运行 `python3 studio.py`，用本地网页选片、调参数、导出。网页不是另一套头像模型，也不需要用户填写 API 密钥。
- **MV 截图壁纸 / 头像**：默认目录 `/Users/yang/Movies/Bili23-Downloader/Yorushika_MV`，使用同一抽帧工具；只处理可解码的成片，跳过下载分片。先均匀采样找场景，再补抽相邻时间。截图头像直接裁切原画，不需要 AI 重绘；宽画幅按电脑构图，人物近景按手机与方图分别选。文件名中的「官方 / 4K / 无损」仅是上传标题，不证明来源或原生画质。

本 Skill 位于项目 `.agents/skills/yorushika-visuals`；所有相对项目路径以包含 `live_wallpaper.py` 和 `studio.py` 的仓库根为准。不要从 Skill 目录直接运行相对项目命令。

## 选片与真实感

1. 抽样接触表只是找线索。必须打开候选原帧看主体、屏幕、日文、曝光与构图，再推荐 3–6 张；至少区分「主唱位」「舞台大屏」「灯光 / 观众氛围」。清晰度分数不是审美分数，也不能证明正在唱歌。
2. 优先用户要求的演唱、热闹灯光、大屏与原生歌词；舞台文字未能看清就写「未辨清」。章节名称来自本地文件标签，不冒充独立核实的官方曲目表。不为好看补写歌词。
3. 找到好构图后可围绕时间点少量补抽，避开眨眼、转场、手或麦克风挡住主体。不同镜头优于同一镜头的多个近似帧。
4. 保留原始提取帧及来源。HDR 素材先转 SDR，再微调曝光、对比度和锐化；禁止用生成模型补出演员面部、观众或屏幕文字。提高输出尺寸只是插值，不是真实细节恢复。
5. **用户已明确手机偏好：默认 cover 铺满裁切，不接受横幅缩小后上下补黑白边。** 以主唱、麦克风和动作完整为先，逐张调整焦点。若要求保留的日文与主唱不能同时进入竖屏，先换帧；确实无法兼顾时说明冲突，不擅自回到补边。只有用户主动要求保留全幅留边时才用 contain。
6. 用户尤其喜欢「大屏 + 主唱剪影 + 原片日文」的电脑壁纸，可增加不同歌曲、灯光和屏幕内容。判断清晰度时分开检查缩略图、真实原帧和最终成品；640px 列表缩略图不能充当主预览或最终导出。放大关键文字与轮廓看运动模糊，优先换成更锐利的相邻帧，不靠过度锐化制造白边。

## 头像与设定边界

已确认设备：本机 MacBook Pro 16 内屏实际 3456×2234；Windows 24 寸 2K 暂按 2560×1440；iPhone 14 Plus 用 1284×2778。用户说模糊主要指网页预览，先检查原帧加载，不盲目给源片做强锐化。

- 角色名称、作者与官方周边必须有来源；「嘻嘻可可」目前只记录为可能指《ヒッチコック》，尚未由用户确认。需要精确还原时先确认具体参考。
- 可以使用有依据的官方视觉元素做个人粉丝二创，但明确标为「原创 fan art / 非官方」，不把新姿势、新动物或新配件写成官方设定。
- 优先少量手绘线条、局部色块、纸面留白，主体在圆形头像裁切安全区。用户要求高清时请求较高原生分辨率并实测返回尺寸，不把 prompt 中的像素值当成工具保证。手机、电脑版重新安排主体与背景，不将方形头像拉伸，不以两侧或上下补边冒充完整壁纸。
- 扩充类型时包括已看过官方参考的《言って。》《雲と幽霊》人物、suis 涂鸦等，不把不同角色仅换颜色当作品种增加。保持每种角色的已核实形状和来源。
- 有参考图片时先查看，再把官方参考、编辑目标和辅助风格图的用途分别交给 `image_gen`。不能声称看过未打开的图片。
- `image_gen` 不可用时说明阻塞并保留需求；不默默改用其他厂商、API、手绘代码占位或要求提供密钥。
