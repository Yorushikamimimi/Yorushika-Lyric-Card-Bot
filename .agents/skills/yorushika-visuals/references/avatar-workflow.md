# GPT 头像工作流

先读 `visual-sources.md` 中对应的官方来源；精确外形需求必须看实际参考图。来源只说明故事时，做故事氛围二创，不声称角色外形已还原。

## 制作

1. 从用户需求确定：角色 / 来源、表情或姿势、简笔程度、配色、背景、用途。能合理决定的细节直接试做，只有角色身份或参考不明确且影响结果时再询问。
2. 调用当前 GPT 环境的内置 `image_gen`。每种方向单独生成一张。不要在一张九宫格里塞多个难以单独使用的头像。用户已要求更多《言って。》等官方小人，并允许将这类插画做成手机 / 电脑壁纸。
3. 自然手绘的含义是有轻微变化的线宽、少量不齐的轮廓、有节制的平涂与留白。不要用一层人工噪声掩盖结构问题，不把「不要太 AI」机械翻译为更复杂的纹理。
4. 查看结果：小尺寸辨识度、圆裁安全区、手和配件是否合理、有没有多余字符、是否保持参考最关键的形状。必要时只修最明显的一项。
5. 如果工具返回项目外的本地生成文件，复制到项目 `output/avatars/` 的新文件名，并记录 prompt 与参考来源。不得用未验证文件路径冒充保存成功。内置工具不返回文件路径时先保留工具展示，并如实说明项目导入尚未完成。

## 清晰度与插画壁纸

- 头像可请求 2048×2048；横屏可请求3840×2160（Mac版3456×2234）、手机按当前设备请求1284×2778，但内置工具只接受文字要求，最终尺寸必须读回验证。没有达到请求尺寸时记录实际值，输出适配版要说明插值，不能称为原生4K。
- 先保证线条和小尺寸辨识度，不用粗重纸纹、虚焦、细密噪声盖住角色。查看局部边缘，避免多次缩放。
- 手机画布以人物和少量情境从上到下构图，电脑画布安排角色与自然留白；背景是画面的一部分。禁止把方形头像缩小塞在长画布中，用黑白矩形补齐。
- 用户已喜欢的原头像作为身份参考时，保持其关键轮廓和色彩，重新布局横竖画布；不重新发明该角色。原图保留，新版用独立文件。
- 新头像保存到 `output/avatars/`，插画壁纸保存到 `output/illustrations/`；同名 JSON 记录 `uses` 数组（如 `["avatar", "phone-wallpaper"]`）、实际尺寸、prompt、来源及是否插值。参考链接放在网页读取的 `reference_url` 字段；复用已有作品的sidecar结构，不把数组写成单个字符串。
- 网页刷新后自动发现这两个目录的图片。不要把接触表/对照图放入 `avatars` 或其他 `avatar*` 目录，否则也会被当作作品；对照图另存批次评审目录。
- MV原画截图头像使用 `kind: "mv-frame-crop"`，记录source、timestamp、原帧裁切坐标和 `generative_edit: false`；GPT生成图使用 `kind: "gpt-generated-fan-art"`，记录prompt与参考，不能混淆。新增素材不适合头像时只补壁纸，不强凑头像数量。

## Prompt 框架

```text
Use case: illustration-story
Asset type: square personal avatar, 1024×1024, usable in a circular crop
Primary request: [角色 / 已核实的官方参考元素] 的原创粉丝二创，非官方。
Reference role: [如果有图片：图 1 是角色依据，图 2 是当前编辑目标；没有就省略]
Subject / pose: [一位主体，清楚的姿势和表情]
Style: [寥寥数笔 / 铅笔线 / 手绘平涂]，线宽轻微自然变化，简洁且有留白。
Palette / background: [有限配色；透明背景须同时设 transparent_background=true]
Composition: 主体留在中央 70–80% 范围，边缘不切断重要配件。
Constraints: 不写日文歌词、不加标题水印，不把原创元素宣称为官方设定。
Avoid: 3D、塑料高光、复杂渲染、繁复装饰、额外肢体、假字、过度光滑的轮廓。
```

## 修改

必须查看现有头像，并用编辑模式将它作为目标。明确「只改 X，保留 Y」，例如：

> 保留现有帽子、脸型、线条颜色和背景，只把手里的咖啡杯换成闭合的素色笔记本；依旧是简笔画。保存为 v2。

不能通过重新随机生成来假装完成了精确局部修改。透明版必须检查实际 alpha；工具仅生成白底时不能声称透明。

## 网页与 Agent 的分工

网页可选择已生成的头像、下载成品、整理并复制下一轮请求。点击复制只复制需求，生成必须回到带此 Skill 与内置图像工具的 GPT / Codex 会话执行。不得展示虚假生成进度或把模板示意当成实际生成结果。
