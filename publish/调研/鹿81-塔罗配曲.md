# **鹿81｜夜鹿大阿卡纳塔罗配曲再调研**

## **C. 22 张大阿卡纳最终推荐汇总表**

本轮以韦特（Rider-Waite-Smith）塔罗的通行牌义、原始牌面符号，以及ヨルシカ官网歌词为依据。配曲关系是本次调研提出的二创解释，并非夜鹿官方设定。

评级标准：

- **强**：歌词直接涉及核心牌义，或明确出现具有辨识度的核心符号。
- **中**：存在具体的歌词依据，但需要进一步解释，或者只对应牌义的一部分。
- **弱**：主要依赖歌名、颜色、气氛，缺乏实质主题对应。

正位牌义优先；涉及逆位、负面表现或反面诠释时单独注明，不把相反的含义强行解释成正位。

《アポリア》最有价值的地方，是同时提供了天空、星星、海洋和水平线这几个真实存在于歌词中的视觉意象，并非仅仅因为歌曲听起来梦幻。

不过要准确区分：它主要表现想象力、好奇心和求知欲，并未明确叙述某人在遭受灾难后得到疗愈。所以本次评强主要依据**核心符号及灵感主题**，而不是声称它完整覆盖星星牌的所有正位含义。

推荐文案方向：

*星星不一定给出答案，却让人依然想知道，水平线的另一边有什么。*

## **B. 剩余十二张大阿卡纳的新配曲**

以下每张牌提供三首候选，按关联强弱排列。候选之间允许交叉，最终22张正式配曲不重复；现有保留的八首歌曲不用于其他牌。

所有画面建议优先采用无人场景、日常物件或动物，不指定 suis 的服装，因此不需要虚构任何演唱会穿搭。本轮不修改此前已经确定的真实 Live 穿搭约束。

### **I 魔术师｜The Magician**

**核心牌义及符号：** 意志、创造、运用已有资源将想法变成现实。原牌人物一手指向天空、一手指向地面，桌上放置权杖、圣杯、宝剑和星币，头顶有无限符号。

## **D. 本轮配曲的关键判断**

为了后续拍板，可以将这些配曲分为三种不同情况。

| 类型               | 对应牌及歌曲                                     | 判断               |
| ---------------- | ------------------------------------------ | ---------------- |
| 歌曲核心主题和牌义直接对应    | 教皇×ヒッチコック、正义×強盗と花束、倒吊人×チノカテ、恶魔×昼鳶、审判×ノーチラス | 最有把握，优先制作        |
| 歌曲、牌义与具体视觉物件同时吻合 | 隐者×六月は雨上がりの街を書く、星星×アポリア、女帝×忘れてください         | 最适合发挥像素塔罗的视觉表达能力 |
| 存在关联，但需要保留解释或矛盾感 | 皇帝×神様のダンス、战车×夜行、节制×風を食む                    | 不要宣传成唯一正确的配曲     |

尤其值得关注的是，倒吊人和恶魔可以构成一组相互对应的作品：《昼鳶》讲被欲望困住，《チノカテ》讲察觉束缚并尝试放下。

审判和世界也可以形成另一组对应：《ノーチラス》讲醒来与重新面对世界，《エイミー》讲人生与创作在一首歌中的收束。

这样的跨牌联系是从歌词主题归纳出来的创作方案，不是官方已经规定的塔罗体系。
