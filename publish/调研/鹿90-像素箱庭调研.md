## **D. 五场 Live 的箱庭构想与样稿推荐**

### **D1. 月と猫のダンス 2024（月与猫之舞）**

**设计方向：打开屋顶的音乐房间。**

这是五场演出中最自然适合箱庭形式的一场。原有舞台就是室内剖面式布景，转换到等距视角时不需要改变它的核心视觉语言。

| 项目   | 构想                                 |
| ---- | ---------------------------------- |
| 底座   | 木地板箱庭，带约 6px 厚的深色底座                |
| 后方布景 | 保留中央大屏、两翼竖格窗及百叶门，将主要布景放在同一个后方平面    |
| 两侧   | 短侧墙、书架、绿植，避免形成封闭的四面墙               |
| 中央   | 一块较大地毯，作为人物活动区域                    |
| 乐手   | 按总计 6 人设计：主唱前方居中，其余乐手分布在中后排，鼓组适当抬高 |
| 主色调  | 暖木棕、米白、墨绿、低饱和蓝紫                    |
| 重点光源 | 窗户透光、中央屏幕、落地灯或舞台局部暖光               |
| 最难之处 | 保证大屏、窗户和书架具有正确透视，又不遮挡乐手            |

**画面重点：** 不要试图将原舞台所有家具全部画出来。中央屏幕、竖格窗、地毯、书架四个视觉符号足以建立场次辨识度。

在原始 270×360 画布中，建议舞台占宽约 228–240px；主墙高约 66–84px，中央大屏投影宽约 70–90px、高约 40–52px。

**难度评估：3/5。**

参考案例：A01 音乐演播室、A03 小型音乐酒吧、A05 书房、A07 简洁卧室。

### **D2. 前世 2024**

**设计方向：深夜书房中的小型室内音乐会。**

这场演出的主要难点是上半场超宽 LED 大屏与下半场写实房间属于不同视觉结构，且乐手人数更多。

建议首版只选择下半场作为箱庭主体，不把两个时间段的布景强行拼成一张假想的真实舞台。

| 项目   | 构想                             |
| ---- | ------------------------------ |
| 底座   | 较宽的深色木地板                       |
| 后方   | 大月亮作为最高视觉元素，书架放在背后或侧翼          |
| 家具   | 木椅、落地灯、小桌子                     |
| 乐手   | 约 9 人，主唱在前方，常规乐队居中，弦乐分组安排在侧后方  |
| 弦乐   | 使用坐姿人物、简化谱架与琴弓，形成小型弦乐区域        |
| 主色调  | 深褐、藏青、月白、暖琥珀                   |
| 最难之处 | 多达 9 人与室内家具的遮挡关系，以及月亮与落地灯的两种光源 |

后续可以将上半场 LED 舞台作为同一个箱庭的第二种状态单独制作，但不建议首版同时处理两套布景。

**难度评估：4/5。**

参考案例：A03、A05、A06、A08。

### **D3. 盗作 2025（盗作）**

**设计方向：夜间祭典屋台搭成的微缩演唱会。**

这一场最适合表现热闹、层次丰富的箱庭，但也最容易因为提灯、彩纸、屋台和火柱太多而显得杂乱。

| 项目   | 构想                          |
| ---- | --------------------------- |
| 底座   | 深灰或深棕的祭典街道地面                |
| 后方   | 两到三组简化屋台，形成连续的背景轮廓          |
| 顶部   | 横跨舞台后方的提灯串、少量彩纸             |
| 两侧   | 低矮音箱与两组火柱                   |
| 乐手   | 6 人，主唱前中，其他乐手分布于后排和两侧       |
| 主色调  | 暗红、朱红、橙黄、深蓝黑                |
| 重点光源 | 提灯及火柱                       |
| 最难之处 | 亮色物件过多，容易让人物被吞没；吊挂灯串也可能遮住头部 |

建议把提灯缩成 8–12 枚具有明确轮廓的小物件，而不是画出几十枚重复灯笼。火柱可以各用约 9×24px 的橙红色阶梯状火焰表示。

**难度评估：4/5。**

参考案例：A02 演唱会舞台、A09 东京街市、A11 海滨祭典。

### **D4. 月光 2022**

**设计方向：漂浮在夜空里的欧洲小镇舞台。**

这场最适合制作室外箱庭，与《月と猫のダンス》的室内结构形成明显区别。它不需要完整高墙，也更方便展示现有的小人。

| 项目   | 构想                          |
| ---- | --------------------------- |
| 底座   | 石板街道，保留可见厚度                 |
| 后方   | 局部欧式建筑立面、台阶和栏杆              |
| 中上方  | 一轮大型新月，保留足够的深色负空间           |
| 两侧   | 橘色玻璃街灯、长椅                   |
| 乐手   | 6 人，围绕中央小型演奏区域布置，鼓组处于后方     |
| 主色调  | 深靛蓝、蓝灰石板、橙色玻璃灯、浅金月光         |
| 最难之处 | 保持月亮、灯光、石板路三者的视觉层次，避免地砖纹理过密 |

新月建议占约 45–65px 的高度，街灯高约 28–36px。鹅卵石只需要通过少量错开的石块轮廓暗示，不需要逐块描完。

**难度评估：2.5/5。**

参考案例：A09 的街道结构、A12 的人物与石板地面。

### **D5. 前世 2021**

**设计方向：在巨型水族箱前演奏的蓝色微缩音乐厅。**

五场中最具差异化的一场。箱庭视觉重心不应该是家具，而应该是水槽内部与舞台之间的空间关系。

| 项目   | 构想                                |
| ---- | --------------------------------- |
| 底座   | 深蓝黑色舞台地板                          |
| 后方   | 大型水槽玻璃面，带清晰的侧面和顶部边缘               |
| 水槽内部 | 分成近、中、远层的鱼群及少量水生植物                |
| 乐手   | 约 10 人，主唱在前方，弦乐四重奏按两组安排，其他乐手置于中后方 |
| 主色调  | 深海蓝、青蓝、青绿、少量冷白                    |
| 重点光源 | 水槽内部向舞台投射的冷色光                     |
| 最难之处 | 10 人的站位、玻璃透明感、水中空间层次以及乐手轮廓的辨识     |

不建议使用大量透明渐变模拟水光。可以采用三至五档固定蓝色色板，通过硬边反光色块、鱼群剪影以及地面的青蓝亮斑表现水下氛围。

**难度评估：5/5。**

参考案例：A10 大型水族馆，以及 A08 的小型鱼缸与透光房间。

## **C. 尺寸建议：画布、地砖与人物比例**

### **C1. 首先确定整数倍放大的画布**

目标成品为 1080×1440，比例 3:4。如果要求原生像素全部等大，并且不使用非整数倍插值，应选择宽、高均能整除目标尺寸的原始画布。

| 原始画布        | 放大倍数   | 输出尺寸          | 适用情况                |
| ----------- | ------ | ------------- | ------------------- |
| 120×160     | 9×     | 1080×1440     | 极简箱庭，六人舞台空间不足       |
| 135×180     | 8×     | 1080×1440     | 极简小模型               |
| 180×240     | 6×     | 1080×1440     | 小型舞台、少量布景           |
| 216×288     | 5×     | 1080×1440     | 紧凑的六人舞台             |
| **270×360** | **4×** | **1080×1440** | **统一五场 Live 的推荐规格** |
| 360×480     | 3×     | 1080×1440     | 大型精细舞台，但绘制量明显增加     |

240×320 本身也是 3:4，但放大到 1080×1440 需要 4.5 倍，不是整数倍。若坚持使用旧规格，可以先放大 4 倍到 960×1280，再放进 1080×1440 的背景画布，左右各留 60px，上下各留 80px。

整数倍放大原则来自 SLYNYRD 的像素画基础教程；具体画布选型为本项目建议。

### **C2. 地砖与舞台尺寸**

建议采用统一的 **24×12px 菱形网格**，通过更小的半格单位摆放乐器和人物。

注意这里的地砖尺寸指几何网格的投影步长，不一定等于包含边缘轮廓的最终精灵图片包围盒。相邻地砖的公共边必须统一处理。

| 参数         | 建议数值          |
| ---------- | ------------- |
| 等距地砖       | 24×12px       |
| 半格单位       | 12×6px        |
| 底座厚度       | 5–8px         |
| 六人舞台逻辑尺寸   | 10×7 或 12×7 格 |
| 九至十人舞台逻辑尺寸 | 12×8 格        |
| 室内后墙高度     | 66–84px       |
| 主唱高度       | 26–30px       |
| 站立乐手高度     | 24–28px       |
| 坐姿乐手高度     | 18–22px       |

例如一个 12×8 格舞台：

- 投影宽度约为 `(12 + 8) × 12 = 240px`。
- 地面投影高度约为 `(12 + 8) × 6 = 120px`。
- 加上墙壁和底座，整体高度约为 190–210px。

在 270×360 的画布上，这个模型仍能保留四周空间、上方标题及必要的背景。

这里必须避免一个误区：3:4 是最终图片比例，**箱庭模型本身不需要强行拉伸成 3:4**。室外模型较扁，可以通过月亮、街灯、标题及背景留白组织竖屏构图。

网格计算依据：[Clint Bellanger — Isometric Tiles Math](https://clintbellanger.net/articles/isometric_math/)。

### **C3. 现有 26px 小人能不能用？**

**能用来做第一版布局，但建议重新绘制少量视角相关像素后再作为正式素材。**

| 人物版本        | 270×360 中占画布高度 | 4 倍输出后高度 | 是否推荐           |
| ----------- | -------------- | -------- | -------------- |
| 26px 迷你版    | 约 7.2%         | 104px    | **推荐作为箱庭人物基础** |
| 32px 新版     | 约 8.9%         | 128px    | 可用于主唱稍突出的版本    |
| 76px 特写版    | 约 21.1%        | 304px    | 不适合直接放进整座舞台    |
| 18–22px 坐姿版 | 约 5%–6.1%      | 72–88px  | 适合鼓手、键盘手及弦乐    |

76px 的人物会迫使整个舞台和家具按照近三倍尺寸重画，六到十名人物很难在同一箱庭里保持清楚的空间关系。

因此推荐：

**保留 26px 人物的服装、发型、色板和角色辨识特征，只重新处理头顶、肩膀、脚部、持乐器动作与投影。** 不需要把五场全部服装从零开始设计。

具体正面人物的适用条件见 B4。

## **B. 等距像素画的五项绘制规范**

### **B1. 2:1 斜线、菱形地砖和剖面墙壁**

#### **① 采用 2:1 像素斜线，而不是严格的 45°斜线**

像素画中通常称为 isometric 的投影，实际上大多使用 dimetric projection（等角轴测的一种近似形式，严格说属于二等轴测投影）。

标准像素斜线是每横向移动 2px，纵向移动 1px。它与水平线的夹角约为 26.565°。

严格数学意义上的等距投影斜线为 30°，在低分辨率下较难形成整齐的像素台阶。因此，游戏像素画经常选择更容易绘制的 2:1 比例。

需要区分三个不同的角度：绕舞台水平旋转约 45°、相机向下俯视约 30°、最终屏幕斜线约 26.565°。它们不是同一个角度。

出处：

- [Drububu — Pixel Art Tutorial](https://drububu.com/tutorial/index.html)
- [Screaming Brain Studios — Isometric Grids](https://screamingbrainstudios.com/isometric-grids/)

两个教程均已打开核对。

#### **② 使用统一的世界坐标到屏幕坐标公式**

现有 Python/PIL 脚本无需引入真正的 3D 渲染器。把物件放在逻辑网格的 `(x, y, z)` 坐标中，再计算其二维投影即可。

```
def iso(x, y, z=0, origin=(135, 120)):    sx = origin[0] + (x - y) * 12    sy = origin[1] + (x + y) * 6 - z    return round(sx), round(sy)
```

此处：

- `x, y` 是地板上的格子坐标。
- `z` 是屏幕像素单位的垂直高度。
- 12 和 6 分别对应 24×12 地砖的半宽、半高。
- `origin` 是可调整的舞台投影起点。

每个箱庭都采用同一坐标体系，人物、地板、书架、台阶和音箱才能真正处于同一个空间中。

这段代码是根据公开投影公式编写的最小示例，未实际运行。

算法出处：[https://clintbellanger.net/articles/isometric_math/](https://clintbellanger.net/articles/isometric_math/)

#### **③ 怎样切墙才像箱庭？**

标准室内箱庭通常保留远离观众的两面墙，将靠近观众的两面墙和屋顶去掉，使内部空间完全可见。

但是 Live 舞台不是普通卧室。像《月と猫のダンス》这种中央大屏配左右布景的舞台，不能直接把大屏从中间折成两面墙。

建议采用：

- 主舞台布景保留在同一后方平面。
- 另一面墙只保留短侧翼。
- 前方两面完全开放。
- 底座前缘保留厚度，强化微缩模型感觉。

参考：[Envato Tuts+ — How to Create an Isometric Pixel Art Room](https://design.tutsplus.com/tutorials/how-to-create-an-isometric-pixel-art-room-in-adobe-photoshop--cms-28573)。

### **B2. 光源方向与三个面的明暗**

**等距箱庭最基础的立体感，不来自纹理，而来自三个面的明暗区别。**

一个简单的箱体通常有三个可见面：

| 面   | 推荐明暗关系 | 作用         |
| --- | ------ | ---------- |
| 顶面  | 最亮     | 表现受到上方灯光照射 |
| 左侧面 | 中间亮度   | 保留物体主要颜色   |
| 右侧面 | 最暗     | 表现体积及背光    |

这是一种假设光源位于左上方时的典型配置，不是所有光照环境的固定物理规律。

例如同一块木材可以使用以下四色：

| 用途   | 示例颜色      |
| ---- | --------- |
| 亮面   | `#B58B65` |
| 主色   | `#916747` |
| 暗面   | `#624633` |
| 深色接缝 | `#41342C` |

上述色值是**个人配色建议**。

对于演唱会舞台，建议将照明拆成两层：

1. **基础空间照明：** 统一规定所有家具、墙面和底座的三个面明暗。
2. **舞台局部照明：** 仅在提灯、街灯、大屏、水槽及附近地面增加额外亮色。

不能为了制造夜景，直接把所有物件压成同一种深蓝色；否则空间体积会消失，人物与背景也会混在一起。

在参考图 A03、A05 和 A08 中可以明显看到局部光源形成的亮区，而房间其他地方仍保持相对安静。这种明暗组织很适合夜鹿舞台。

出处：[Drububu 像素立方体明暗教程](https://drububu.com/tutorial/index.html)。

### **B3. 小物件要画几个像素才能认出来？**

没有找到可以证明某种乐器至少需要多少像素才能被人辨识的统一实验数据。因此，下面给出的是**以 26px 人物为比例基准的试做尺寸**，而不是业内硬标准。

| 物件     | 推荐原生尺寸（宽×高）   | 最少保留的辨识特征      |
| ------ | ------------- | -------------- |
| 麦克风与支架 | 4×20px        | 顶端话筒、细杆、底座     |
| 电吉他／贝斯 | 7–10×17–20px  | 不对称琴身、细长琴颈、背带  |
| 小提琴    | 6–8×9–12px    | 琴身轮廓、琴颈、琴弓     |
| 大提琴    | 9–12×18–23px  | 大琴身、长琴颈、下方支撑   |
| 键盘     | 20–26×12–16px | 黑白琴键、厚度、支撑架    |
| 鼓组     | 28–36×22–28px | 大鼓、鼓面、两枚镲片     |
| 舞台音箱   | 10–14×16–20px | 箱体顶面、正面圆形单元    |
| 提灯     | 6–9×9–12px    | 外轮廓、亮色灯芯、上下深色边 |
| 落地灯    | 9–12×25–32px  | 灯罩、细杆、底座       |
| 玻璃街灯   | 8–12×28–36px  | 玻璃灯箱、杆、顶盖      |
| 书架     | 18–26×28–44px | 三至四层横隔板、成组竖色块  |
| 木椅     | 10–15×16–22px | 椅背、坐面、前后腿      |
| 绿植     | 8–14×14–20px  | 花盆、两到三组叶片色块    |

尺寸指物件最终二维精灵的近似包围盒，不是它在逻辑地砖上的占地大小。

最有效的简化方式是先画轮廓，再增加一个或两个决定物件身份的细节。

例如：

- 音箱不需要绘制完整网罩纹理，一个深色箱体加两个圆形单元就够。
- 书架不必逐本画书名，几组大小不同的竖色块即可形成阅读感。
- 小提琴优先保留形状和琴弓，而不是四根琴弦。
- 键盘可以用交错的黑白条纹表达琴键，不必严格还原全部键数。

依据：[SLYNYRD — Pixelblog 2: Texture](https://www.slynyrd.com/blog/2018/2/15/pixelblog-2-texture)。作者建议将纹理简化为少量像素簇、控制分布与密度，并避免无意义的孤立像素。

Texture — SLYNYRD

参考图 A01、A03 的乐器以及 A07 的小家具都能提供实际视觉依据。

### **B4. 正面小人直接放进等距场景会不会别扭？**

**可以直接放，但适合原型验证，不宜默认所有正式人物都保持完全平视正面。**

主要原因是地板与家具已经从斜上方观察，而原来的人物可能完全看不到头顶、肩顶和鞋面。如果其他物件具有明确立体结构，人物就容易显得像贴在场景里的纸片。

#### **现成正面人物有三种复用路线**

| 路线             | 做法                    | 成本  | 效果判断            |
| -------------- | --------------------- | --- | --------------- |
| A. 完全复用正面小人    | 只调整脚底位置和阴影            | 最低  | 可用于摆位预览；可能缺乏空间感 |
| B. 近正面视角改造     | 保留服装与脸部，微调头顶、肩膀、鞋面及手臂 | 低至中 | **最推荐**         |
| C. 完整 3/4 等距人物 | 重新绘制斜上方可见的头、躯干、四肢及乐器  | 高   | 空间感最好，但工作量最大    |

#### **有没有类似游戏案例？**

有，但需要区分严格等距角色与视觉上接近正面的角色。

- **Habbo Hotel：** 等距房间中使用二维人物精灵，支持不同身体及头部朝向。参考图 A02 与额外角色案例中，人物可以保持朝向屏幕或偏向观众的姿态，不必全部展示侧面或背面。
- **PewDiePie's Tuber Simulator：** A01 的房间有角度明确的等距家具，同时使用较简化、接近正面的卡通人物。
- **Final Fantasy Tactics：** A12 展示了人物精灵与斜向地面结合的方式。不过人物通常具有 3/4 视角，并不是直接把纯平视正面立绘贴进去。

这些例子支持使用**二维人物精灵搭配等距场景**，也支持针对静态画面选择最有辨识度的朝向。但本次没有找到足够证据证明，一个完全未经视角修正的平视正面小人必然能自然融入任何等距画面。

#### **具体怎么改现有的 26px 夜鹿小人？**

以下是**个人经验性设计建议**，实际改动量取决于现有人物的像素结构：

| 部位 | 建议                             |
| -- | ------------------------------ |
| 发型 | 保留原轮廓和颜色，增加约 1–2px 的头顶亮面       |
| 脸部 | 尽量保留现有辨识特征，不必强制所有人物露出侧脸        |
| 肩膀 | 使用少量不对称色块表现前后关系                |
| 身体 | 保留服装正面的关键图案，略微表现肩部与衣服厚度        |
| 鞋子 | 重新绘制鞋面和接地位置，不只保留平视轮廓           |
| 乐器 | 重画持握角度，保证吉他、琴弓等不会像悬浮在身前        |
| 阴影 | 在脚下加入约 7–12px 宽、2–4px 高的深色接地阴影 |
| 坐姿 | 鼓手、键盘手、弦乐手单独设计，不能简单缩短站立小人      |

建议主唱保持略偏正面的朝向，让服装辨识度最高；其他乐手根据站位和乐器适当向左右转动。

**不需要设计游戏式八方向人物动画。** 你的目标是固定镜头下的舞台箱庭，每个角色有一个适合当前构图的姿态就够了。

### **B5. 常见的坑**

| 问题        | 为什么会出错                   | 处理方法                                  |
| --------- | ------------------------ | ------------------------------------- |
| 斜线台阶不一致   | 2:1、3:1、1:1 等随意混用会破坏平行关系 | 用统一投影坐标计算结构边                          |
| 使用抗锯齿     | 产生额外边缘色，像素颗粒不一致          | 在原生分辨率直接绘制硬边                          |
| 直接旋转正面小人  | 二维旋转无法恢复头顶和侧面信息          | 保留设计元素，手动补绘目标角度                       |
| 物件比例混乱    | 鼓组可能比人物过大、椅子过小           | 先确定 26px 人物，再统一物件比例                   |
| 所有表面都填满纹理 | 没有视觉主次，手机上容易变成噪点         | 大面留空，只在局部增加材质                         |
| 灯光全屏泛亮    | 局部光源失去重点，破坏固定色板          | 用有限层级的局部亮色块                           |
| 人物脚底没有阴影  | 看起来悬浮在地板上                | 使用统一的脚底锚点和接地阴影                        |
| 前景家具遮住人物  | 单纯按平面坐标排序容易出错            | 依据地面占地、脚底及物体高度安排遮挡                    |
| 后墙折断大屏    | 把普通房间模板生搬硬套到演唱会          | 保留主要舞台背景的真实平面                         |
| 最终非整数倍缩放  | 不同像素可能变成不同宽度             | 使用 `Image.Resampling.NEAREST` 进行整数倍放大 |

### **E2. 推荐的最小自研绘图组件**

实际上，现有 PIL 脚本只需要增加一组较小的等距绘制接口，不需要另起大型渲染引擎。

| 组件                   | 职责                |
| -------------------- | ----------------- |
| `iso(x, y, z)`       | 世界坐标转换到屏幕像素坐标     |
| `draw_tile()`        | 绘制菱形地砖，处理公共边      |
| `draw_box()`         | 绘制具有三个明暗面的立体箱体    |
| `draw_wall()`        | 绘制墙面、窗户、门及墙体厚度    |
| `draw_steps()`       | 绘制舞台台阶、抬高的鼓台      |
| `draw_sprite()`      | 将自绘人物、乐器定位到脚底或支撑面 |
| `draw_shadow()`      | 绘制物件接地阴影          |
| `draw_light_patch()` | 绘制硬边的局部照明色块       |
| `render_scene()`     | 统一处理舞台各层的绘制顺序     |

### **E3. 遮挡关系怎么处理？**

建议先使用可控的固定绘制层，再对人物和小型道具进行深度排序。

推荐顺序：

```
背景
  ↓
舞台底座
  ↓
地板、后墙、远处布景
  ↓
地毯、地面光斑、接地阴影
  ↓
远处乐手及乐器
  ↓
中间乐手及乐器
  ↓
前方主唱及音箱
  ↓
必要的前景遮挡
  ↓
悬挂灯饰和其他局部前景
  ↓
整数倍放大输出
```

同一高度、占地较小的物件，可以初步按照 `x + y` 或投影后的脚底纵坐标从后向前排序。

但书架、台阶、巨型水槽等多格、高体积物件，不能仅按一个 `y` 值解决所有遮挡。对于固定构图的静态箱庭，手动指定遮挡层和绘制顺序通常比实现复杂的通用深度排序系统更直接。

依据：[https://erikonarheim.com/posts/handling-height-in-isometric/](https://erikonarheim.com/posts/handling-height-in-isometric/)

**工具选型结论：继续使用 PIL，自己实现等距坐标与少量通用图元即可。** ProceduralPixelArt 最适合作为算法参考，不建议第一版便引入游戏引擎或额外的房间编辑系统。
