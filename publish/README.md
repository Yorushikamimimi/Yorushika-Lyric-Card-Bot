# 发布台账

`ledger.csv` 是夜鹿二创在各平台发出的帖子记录，**一平台一帖一行**（同一组图发小红书和抖音就是两行）。UTF-8、逗号分隔、第一行是字段名，夜灯控制台面板直接读它。

| 字段 | 含义 |
|---|---|
| `date` | 发布日期 `YYYY-MM-DD` |
| `platform` | 小红书／抖音／Instagram／X |
| `works` | 这帖用到的作品，填工房清单编号（如 `yoru-zense2024-n`），多张用 `;` 隔开，按演出顺序 |
| `title` | 帖子标题 |
| `url` | 帖子链接，本人从创作者后台抄来；没给就空着 |
| `ai_label` | 是否标了 AI 辅助／AI 生成：`是`／`否`，不确定就空着 |
| `d3_views` `d3_likes` `d3_saves` `d3_comments` | 发布满三天的播放或浏览、点赞、收藏、评论 |
| `d7_views` `d7_likes` `d7_saves` `d7_comments` | 发布满七天的同上四项 |
| `note` | 备注 |
| `reviewed_by` | 这帖是哪边审核放行的，写 Harness（如 `Claude 桌面版 Code`、`反重力`），见 [审核职责.md](审核职责.md) |

- 数据只填本人抄来的数，没到时间或没给就空着，不估。到了时间但后台确实没有这一项（比如抖音图文不显示收藏）填 `NA`，不填 0。三天、七天都记后台显示的**累计值**，要看新增自己相减。Claude 不登录平台、不碰 Cookie。
- 本人发完给链接和截图，第 3、7 天的数据也截图给；Claude 照截图填。
- 不记账号名以外的个人信息（手机号、绑定邮箱、私信、地址等）。
- `python3 publish/ledger_due.py` 列出缺链接、到了三天／七天还没补数据的行。

## 四平台规格与动图参考（11-19 鹿21 调研核实）

以下结论区分「官方公开文档已核实」与「未取得普通 App 端硬规定（待实发确认）」：

| 平台 | 图文比例／文件 | GIF 直发支持 | 短视频 MP4 规格 | AI 声明 |
|---|---|---|---|---|
| 小红书 | 商家笔记课程建议 `3:4`；普通笔记 2:1/分辨率/文件上限 unknown | unknown（是否保持循环未核实） | 普通笔记时长/帧率/大小 unknown（不套用电商商品规则） | 平台有 AI 治理规则；个人端开关精确按钮名称待实发核对 |
| 抖音 | 分享 SDK 宽高比 `1/2.2～2.2`（2:1 与 3:4 均在内）；直发开放平台图 `≤100 MB` | H5 单图分享入口接收 `.gif`、多图不支持；是否保持循环 unknown | 直发 API 支持 MP4，时长 `≤15 分钟`、分片上传 `≤4 GB`；帧率 unknown | 官方安全中心公告写明路径 `高级设置 → 发文助手自主声明 → 内容由 AI 生成`（界面改版时人工核对） |
| Instagram | 官方发布 API 仅认 JPEG、`4:5～1.91:1`、`≤8 MB`、宽 `320～1440 px`（2:1 与 3:4 均超 API 口径）；App 端处理 unknown | 官方发布 API 仅收 JPEG、不收 GIF；App 端 unknown | Reels API 支持 MP4/MOV、`H.264/H.265`、`23～60 fps`、`3 秒～15 分钟`、`≤300 MB`、推荐 `9:16` | Meta `AI info` 标签；发布 API 支持 `is_ai_generated=true` |
| X（Twitter） | 官方帮助页确认单图 `2:1～3:4` 完整显示；普通帖图 `≤5 MB`（FAQ 索引） | 官方明确确认原生循环 GIF 自动播放；网页 `≤15 MB`／移动 `≤5 MB`，**不要把 GIF 和多图混排** | 普通非订阅号网页上限 `140 秒 / ≤512 MB`；Media Studio 为 `MP4/H.264/≤60fps/≤8 GB`（不可互套） | 官方有 `Made with AI` 识别/标注与禁误导政策，未见普通个人二创必选发布开关 |

- **跨平台实操取舍**：
  1. **像素循环动图优先统一导出 MP4**（避开小红书／抖音／IG 对直传 GIF 是否保留动效的不确定性）；**X 可单帖发原生循环 GIF**，不与静态图混在同一条里。
  2. **Instagram 注意裁切**：`3840×1920`（2:1）与 `3:4` 均超出 IG 发布 API 的 `4:5～1.91:1` 区间，准备发 IG 时需提前按 `4:5` 或 `1.91:1` 校验显示。
     - 11-21 实发定法：IG 用 4:5 黑边版（1440×1800 JPEG，像素图 3840→1440 用 BOX 缩放每格正好 6px），帖内顺序同小红书；配文日英双语＋「AI 辅助创作｜非官方二创」，打开「添加 AI 标签」。
  3. **无音轨纯画面 MP4** 四端普通 App 是否均无障碍放行尚缺统一官方原文，首条试发时按实测记录回写本表。
